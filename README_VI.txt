MEXU PANEL - ANDROID WEBVIEW PROJECT

Đây là mã nguồn dự án Android, chưa phải APK đã biên dịch.
Cách build đơn giản:
1. Giải nén ZIP.
2. Đưa thư mục MEXU_PANEL_ANDROID lên GitHub.
3. Mở tab Actions và chạy workflow "Build MEXU PANEL APK".
4. Tải artifact MEXU-PANEL-APK, bên trong có app-debug.apk.

Có thể mở bằng Android Studio rồi chọn Build > Build APK(s).

Lưu ý:
- Các nút chức năng/key và thời gian chờ trong HTML là mô phỏng giao diện offline.
- Ứng dụng không chỉnh sửa game hoặc cung cấp tính năng can thiệp Free Fire.
- Nút vào game chỉ thử mở package Free Fire nếu đã cài đặt.
- Bộ tạo key offline không phải hệ thống cấp phép an toàn; key có thể bị giả mạo.
